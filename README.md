# DSA Learning Roadmap & Practice Questions

A personal roadmap to learn **Data Structures and Algorithms (DSA)**
step by step and prepare for **fresher-level coding interviews**.

This repository is my learning journey. I use it to track the topics I
study, practise important coding questions, understand common
problem-solving patterns, and revise before interviews. The goal is to
build a strong foundation by solving problems consistently rather than
collecting long notes.

## 📌 Pattern Abbreviations

  -----------------------------------------------------------------------
  Abbreviation                        Meaning
  ----------------------------------- -----------------------------------
  **TP**                              Two Pointers

  **HT**                              Hashing / Hash Table

  **Freq**                            Frequency counting

  **PS**                              Prefix Sum

  **SW**                              Sliding Window

  **XOR**                             Bitwise XOR

  **Kadane's Algorithm**              A pattern used to solve the Maximum
                                      Subarray problem
  -----------------------------------------------------------------------

Patterns can overlap. A problem may require more than one technique.

## ✅ My Problem-Solving Routine

For each question:

1.  **Understand the problem:** Identify the input, expected output, and
    constraints.
2.  **Try a basic approach:** Make sure you understand the logic before
    optimizing.
3.  **Choose a pattern:** Check whether Two Pointers, Hashing, Prefix
    Sum, Sliding Window, or another technique fits.
4.  **Write the code:** Solve it independently before looking at a
    solution.
5.  **Test edge cases:** Try empty or small inputs, duplicates, negative
    values, and boundary cases when relevant.
6.  **Analyse complexity:** Write down the time and auxiliary space
    complexity.
7.  **Revise later:** Re-solve questions that were difficult without
    copying the earlier code.
